# Local SEO Mastery

A complete self-study course: **240 lessons · 39 modules · 10 levels**, taking a reader from complete beginner to top-tier Local SEO practitioner.

## How to open it

Double-click `index.html`. It runs in any modern browser with no server, no install and no internet connection required.

All progress is saved in that browser only (localStorage). Use **Export backup** on the dashboard before clearing browser data or moving to another computer.

## The skipped-lesson warning

If you open a lesson while earlier lessons are still unticked, a warning banner appears at the top showing **how many you skipped and their exact names**, each one clickable. You can jump to the first one you missed, or dismiss the banner and continue.

## Mastery ranks

Eight ranks unlock as lessons are completed: Beginner (24) → Foundational (48) → Intermediate (96) → Advanced (144) → Expert (174) → Elite (198) → Master (219) → **Top 1%** (240).

## Writing standard

Written for readers whose first language is not English: short sentences, common words, one idea per sentence, no idioms. Every technical term is explained in plain words the first time it appears.

## Files

```
index.html          the whole application shell
assets/styles.css   all styling
assets/app.js       all logic: routing, progress, quizzes, skip warnings, search
data/curriculum.js  the 240-lesson index (levels, modules, titles)
data/l{N}m{N}.js    lesson content, one file per module (39 files)
```

To edit a lesson, open its module file and edit the text. The content format is
plain and readable — `h:` heading, `p:` paragraph, `l:` bullets, `n:` numbered,
`tip:` / `warn:` / `ex:` callouts, `term:` definition, `table:` table.
